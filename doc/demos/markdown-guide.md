# Markdown 使用手册

欢迎使用 **文档工坊**。这个示例展示 Markdown 的预览、搜索、文本提取与编辑。

## 文字与链接

支持 **加粗**、*斜体*、***粗斜体***、~~删除线~~，以及 `inline code`。

可以阅读 [Markdown 格式介绍](https://commonmark.org/)。链接需要手动点击，不自动加载外部内容。

> 文档只在本地浏览器中处理，不上传服务器。
>
> 编辑后可以下载 Markdown，或下载 DOCX 保留字体颜色、字号等富文本样式。

## 格式支持表

| 功能 | 状态 | 说明 |
| :--- | :---: | ---: |
| 标题与文字样式 | 支持 | 最多六级标题 |
| 引用与代码块 | 支持 | 保留代码中的缩进 |
| 表格与任务列表 | 支持 | 可编辑表格内容 |
| HTML 与图片 | 文本显示 | 不执行脚本、不自动加载资源 |

## 代码示例

```javascript
const formats = ['doc', 'docx', 'pdf', 'md'];

function welcome(name) {
  return `你好，${name}！`;
}

console.log(welcome('Markdown'));
```

代码块中的 **星号** 是普通文字：

```text
**这里不会加粗**
<script>这里不会执行</script>
  缩进会保留
```

## 编辑与导出

点击“编辑文档”修改内容，使用“文字 / 表格”工具切换编辑项目。

Markdown 保留标题、强调、链接、引用、代码和普通表格。颜色、字号、下划线、对齐和合并单元格等效果请通过“转换 / 下载”选择 DOCX 保留。也可以选择 PDF，生成可搜索、可复制文字的阅读版本。
